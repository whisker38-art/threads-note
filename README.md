# Threads 자동 게시

Threads 공식 API(Meta)로 글을 올리는 최소 구성입니다.

## 준비 (한 번만)

Meta for Developers 에서 아래 순서로 설정하고 토큰을 받습니다.

1. **앱 만들기** — 내 앱 → 앱 만들기 → 앱 이름(예: `Threads 자동 업로드`) + 연락처 이메일
2. **이용 사례에서 `Threads API 액세스` 선택** → 다음
3. **비즈니스 포트폴리오** — "아직 연결하고 싶지 않음" → 다음 → 요구 사항(빈 화면) → 다음 → 개요 확인 → 앱 만들기
4. **권한 확인** — 이용 사례 → Threads API 액세스 → 맞춤 설정 → 권한 및 기능
   → `threads_basic`, `threads_content_publish` 두 개를 **+추가** (상태가 "테스트 준비 완료"가 되면 됨)
5. **테스터 추가** — 같은 화면 좌측 `설정` → 맨 아래 `Threads 테스터 추가 또는 삭제`
   → 사람 추가 → 역할 **Threads 테스터** → 본인 Threads 사용자 이름 검색 후 추가
6. **초대 수락** — threads.com 로그인 → 좌측 하단 더 보기 → 설정 → 설정 더 보기 → 웹사이트 권한
   → **초대** 탭 → 방금 만든 앱의 `수락`
7. **토큰 발급** — Meta 개발자 사이트로 복귀 → 같은 설정 화면 아래 `사용자 토큰 생성기`
   → 계정 오른쪽 `액세스 토큰 생성하기` → 권한 확인 후 계속 → `이해합니다` 체크 → `복사` → Done
8. **토큰 저장** — `.env.example` 을 복사해 `.env` 로 만들고 `THREADS_ACCESS_TOKEN=` 뒤에 붙여넣기

> 토큰은 `.env` 에만 둡니다. 캡처·메신저·블로그 어디에도 붙여넣지 마세요.
> `.gitignore` 에 이미 `.env` 가 들어 있습니다.

## 쓰는 법

```bash
# 토큰이 살아있는지 + 내 user id 확인
node threads_publish.mjs --me

# 글만 올리기
node threads_publish.mjs --text "오늘의 글"

# 파일에 써둔 내용을 올리기
node threads_publish.mjs --file post.txt

# 이미지와 같이 (이미지는 외부에서 열리는 공개 URL이어야 합니다)
node threads_publish.mjs --text "내용" --image https://example.com/a.jpg

# 남의 글에 답글
node threads_publish.mjs --text "답글" --reply-to 17912345678901234

# 올리지 않고 점검만
node threads_publish.mjs --text "내용" --dry
```

## 알아둘 것

- 한 게시물 본문은 **500자**까지입니다. 스크립트가 미리 막습니다.
- 게시는 항상 **컨테이너 생성 → 발행** 두 단계입니다. 이미지·영상은 메타가 내려받아 처리할 시간이 필요해서 스크립트가 상태를 확인하며 기다립니다.
- 이미지는 **로컬 파일을 올릴 수 없습니다.** 외부에서 접근 가능한 공개 URL이어야 합니다.
- 발행한 글은 `logs/posts.jsonl` 에 한 줄씩 기록됩니다.
- 토큰은 장기 토큰이지만 **60일**이면 만료됩니다. 만료되면 7번을 다시 하거나 갱신 호출을 붙이면 됩니다.

## API가 해주는 것 / 안 해주는 것

| 할 수 있음 | 공식 API에 없음 |
|---|---|
| 글·이미지·영상 게시 | 자동 팔로우 / 언팔로우 |
| 답글 달기 | 남의 글 자동 좋아요 |
| 내 글 인사이트 조회 | 피드 무제한 수집 |
| 키워드 검색 (권한 추가 시) | |

오른쪽 칸은 API로 제공되지 않습니다. 브라우저 자동화로 흉내내는 건 Meta 플랫폼 약관 위반이고
계정 제한·정지 사유입니다.
